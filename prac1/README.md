# Bash-задания (РТУ МИРЭА)

Набор решений практических задач по bash-скриптингу. Все скрипты
проверены **ShellCheck** и не выдают предупреждений.

## Требования

- bash (протестировано на bash 5.x, Linux)
- стандартные утилиты: `grep`, `awk`, `sed`, `sort`, `find`, `tar`, `md5sum`, `file`

## Содержимое

| Файл | Задача | Использование |
|---|---|---|
| `task1_users.sh` | Отсортированный список пользователей из `/etc/passwd` | `./task1_users.sh [файл]` |
| `task2_protocols.sh` | Топ-N протоколов из `/etc/protocols` по номеру порта | `./task2_protocols.sh [файл] [N]` |
| `banner` | Баннер в рамке для произвольного текста | `./banner "текст"` |
| `task4_identifiers.sh` | Уникальные идентификаторы (C/C++/Java) из файла | `./task4_identifiers.sh файл.c` |
| `reg` | Регистрация команды в `/usr/local/bin` с правами 755 | `./reg banner` |
| `task6_check_comments.sh` | Проверка комментария в первой строке `.c`/`.js`/`.py` файлов | `./task6_check_comments.sh каталог` |
| `task7_find_duplicates.sh` | Поиск файлов-дубликатов по содержимому (рекурсивно) | `./task7_find_duplicates.sh каталог` |
| `task8_tar_by_ext.sh` | Архивация файлов с заданным расширением в tar | `./task8_tar_by_ext.sh расширение [каталог]` |
| `task9_spaces_to_tabs.sh` | Замена 4 пробелов на символ табуляции | `./task9_spaces_to_tabs.sh вход выход` |
| `task10_empty_files.sh` | Список пустых текстовых файлов в каталоге | `./task10_empty_files.sh каталог` |

## Подробности по задачам

### Задача 1 — список пользователей
Первое поле строки `/etc/passwd` (до `:`) извлекается через
`grep -oE '^[^:]+'`, затем сортируется через `sort`.

### Задача 2 — топ протоколов
Комментарии и пустые строки отбрасываются (`grep -vE '^#|^$'`),
`awk` меняет местами номер и имя, `sort -rn` сортирует числа по
убыванию, `head` берёт первые N.

### Задача 3 — banner
Ширина рамки вычисляется динамически из длины `${#text}`, рамка
рисуется через `printf '%*s'` + `tr`.

### Задача 4 — идентификаторы
`grep -oE '[A-Za-z_][A-Za-z0-9_]*'` извлекает все подстроки по
правилу идентификатора C/C++/Java, `sort -u` убирает повторы и
сортирует, результат склеивается в одну строку.

### Задача 5 — reg
Устанавливает права `755` (`rwxr-xr-x`) и копирует файл в
`/usr/local/bin` (через `sudo`, если нет прав записи напрямую).

### Задача 6 — проверка комментариев
Для `.c`/`.js` комментарий — это `//` или `/*` в начале первой
строки; для `.py` — `#`. Поиск файлов рекурсивный, имена файлов
обрабатываются безопасно (`-print0` / `read -d ''`).

### Задача 7 — файлы-дубликаты
Для каждого файла считается `md5sum`; файлы с одинаковым хэшем —
дубликаты. Результаты группируются по хэшу через `awk`, выводятся
только группы из 2+ файлов.

### Задача 8 — архивация по расширению
`find` собирает файлы с заданным расширением (`-name "*.ext"`),
результат передаётся в `tar -cf`.

### Задача 9 — пробелы → табы
`sed 's/    /\t/g'` заменяет каждую последовательность из 4
пробелов на символ табуляции.

### Задача 10 — пустые файлы
`find -type f -empty` ищет файлы нулевого размера в указанном
каталоге (без рекурсии), дополнительно проверяется MIME-тип через
`file`, чтобы исключить нетекстовые пустые файлы.

## Проверка ShellCheck

```bash
shellcheck *.sh banner reg
```

Все скрипты проходят без предупреждений.
